# Changelog / Cronologia delle modifiche

## Documentation update / Aggiornamento della documentazione

**English:** Added matching English and Italian guides, clearer installation and troubleshooting, and project presentation for GitHub. Extension behavior and version are unchanged.

**Italiano:** Aggiunte guide equivalenti in inglese e italiano, installazione e risoluzione dei problemi più chiare, e una presentazione per GitHub. Comportamento e versione dell'estensione restano invariati.

## 0.9.0

### English

- Removed whole-chat export.
- Added right-click export for selected content.
- Improved answer detection in containers shared by questions and answers.
- Kept the previous PDF engine.
- Detection across every variation of the live ChatGPT page remains unverified.

### Italiano

- Rimossa l'esportazione dell'intera chat.
- Aggiunta l'esportazione del contenuto selezionato dal menu del tasto destro.
- Migliorato il riconoscimento delle risposte nei contenitori condivisi con le domande.
- Conservato il motore PDF precedente.
- Il riconoscimento di tutte le varianti della pagina reale di ChatGPT resta da verificare.

## 0.8.0

### English

- Restored buttons removed or cloned during page updates.
- Detected text and attribute changes during answer generation.
- Kept selection associated with the correct message when content changes.

### Italiano

- Ripristinati i pulsanti rimossi o clonati durante gli aggiornamenti della pagina.
- Riconosciute le modifiche a testo e attributi durante la generazione delle risposte.
- Mantenuto il collegamento della selezione al messaggio corretto quando cambia il contenuto.

## 0.7.0

### English

- Bundled local KaTeX styles and fonts.
- Improved formulas, paragraphs, tables and code block handling.
- Added asynchronous preparation with a bounded wait for resources.
- Made printing available through the button in the ready preview.

### Italiano

- Inclusi stili e font KaTeX locali.
- Migliorata la gestione di formule, paragrafi, tabelle e blocchi di codice.
- Aggiunta la preparazione asincrona con attesa limitata delle risorse.
- Resa disponibile la stampa tramite il pulsante nell'anteprima pronta.
